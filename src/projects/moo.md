Moo was an attempt at a Smalltalk-shaped language in portable C: classes and methods, symbols, pool dictionaries, and a managed object memory to hold them all. Writing it turned questions about dispatch, object layout and control flow into working C code. Hak carries the same questions forward in a smaller, command-oriented form.
